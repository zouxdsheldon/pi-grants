使用说明 / How to use
  1. 本文件已内置一份基于你真实 CV 与 Scholar 记录生成的完整报告——不填任何东西，直接点「报告」标签就能读、能下载。
  2. 想重新生成：在「输入」里上传 CV（PDF/TXT/MD）、粘贴 Scholar 页面文本、填补充信息，填入你自己的 Anthropic API Key，点「运行完整分析」。
  3. API Key 只存在本机 localStorage，只发往 api.anthropic.com，不经任何第三方。不确定就别填——内置报告已经可用。
  4. 「报告」里可下载 Markdown / 独立 HTML / PDF（走浏览器打印），或复制全文。
  5. 「历史」保留最近 10 版，可回载、可看逐行差异。整个会话可导出/导入 JSON。
