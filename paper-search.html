⚠ 先记住这一条，它能省掉一个严重误判： 把 3 个以上词用 AND 串起来，PubMed 返回 0 篇是常态，这不是「研究空白」的证据 —— 只是检索式太窄。 本工具因此内置子句阶梯：只要全交集 < 5 篇，它会自动把检索式拆成单词计数与两两组合计数并列给你看。 判断空白要看两两组合的最小值，不是看全交集。
同理，PubMed 若把引号短语判为「未收录」会整条丢掉该短语，AND 随即塌成 0 —— 本工具会显式警告并自动去引号重试。 这两个坑都是实测踩到的：一次 21 条检索式里有 20 条因为这两个原因报 0，看起来像「遍地空白」。
① 组检索式
列头可点击排序。方法/数字/空白三列是确定性抽取，展开可看触发它的原句。
每次检索都记一行：执行时间、实际送给 PubMed 的检索式、全库命中数、抓取数、收进总表数、子句阶梯结论。 这一页的用途是三个月后你还能复现当时那次检索。
这个工具做什么
把一次关键词检索变成一张可核对的表，并把每次检索记进台账，最后汇总成一张跨检索的总表 —— 供你以后回查与追踪。

抽取是确定性的，不调大模型
方法、数字、空白三列全部由词边界正则在摘要原文上抽取，每条都附触发它的整句，你可以当场核对。 所以屏幕上不会有「读着有道理但查不到出处」的句子。

实测能力上限（在 12 周阅读计划那 68 篇真实摘要上逐项测过）
· 方法抽取：50 / 68 篇有命中（共 104 条）
· 效应量：10 / 68 篇 —— 这不是漏抓，我用宽模式在原文里核对过，真实分布正好也是 10。机制类与结构类摘要普遍不报倍数/p 值。
· 空白句：18 / 68 篇 —— 作者的「尚不清楚」多写在 Discussion 末尾而非摘要。
· 摘要分段：只有 4 / 68 是出版方结构化摘要（标 来自出版方），其余 64 篇按线索句规则推断（标 规则推断）。推断会出错，所以两者用不同徽章区分。

已知局限 —— 请当成读数说明
· 命中数是检索当日值，会随 PubMed 收录变化。台账里记了执行时间，就是为了让你知道那个数字是什么时候的。
· 被引数来自 Europe PMC，它经常 503。取不到时显示「未获取」而不是 0 —— 抓取失败和真的零引用长得一模一样，不能混为一谈。
· 全交集为 0 不是空白证据（见页首红框）。判断空白请看子句阶梯里两两组合的最小值；即便它是 0，也只说明这两个词从未在标题/摘要里共现，不等于没人想过这个问题。
· 只检索 PubMed。预印本（bioRxiv/medRxiv）、arXiv、以及未被 PubMed 收录的期刊抓不到。想覆盖预印本请另用本站「🔔 文献追踪」面板。
· 抽取只看摘要。关键图、对照、参考文献这三类信息从摘要原则上得不到 —— 要那些请用「🔎 论文速读与笔记工具」逐篇做笔记。

数据存在哪
总表与台账都存在你自己的浏览器里（localStorage），不上传任何服务器。换电脑或清缓存前请先导出。

导出格式的诚实说明
导出的 Word/Excel 是 HTML 封装的 .doc / .xls：Word 与 Excel 都能直接打开、再另存为原生格式，但它不是 OOXML。 本站是纯静态页（没有后端），这是能做到的上限，所以按 .doc/.xls 命名而不谎称 .docx。CSV 与 Markdown 是标准文本格式。
